# ADR-0008: Windows Notion uses the official MSIX boundary

- Status: Accepted
- Date: 2026-09-23
- Extends: ADR-0006

## Context

Windows bootstrap originally declared `winget:Notion.Notion` under `[bootstrap.packages]`.

On a fresh Windows setup, WinGet successfully downloaded Notion 7.35.1 but the vendor Setup EXE terminated with Windows status `3221225477` (`0xC0000005`). Because the package was part of mise's mandatory package phase, this single GUI installer failure aborted the remaining machine bootstrap.

Notion also publishes an official Windows MSIX distribution and documents separate x64 and arm64 endpoints. This is a vendor-supported installation channel and fits ADR-0006's allowance for platform adapters to own vendor-specific boundaries that are not safely expressible in the common mise package phase.

## Decision

1. Remove `winget:Notion.Notion` from the mandatory mise package list.
2. The root Windows PowerShell adapter installs Notion from the official Notion MSIX endpoint.
3. Select the endpoint from the host architecture:
   - x64: `https://www.notion.com/desktop/windows-msix/download`
   - arm64: `https://www.notion.com/desktop/windows-msix-arm/download`
4. Detect an existing legacy WinGet/NSIS Notion installation or an installed Notion AppX/MSIX package and skip reinstalling it.
5. A Notion-only install failure emits a warning and does not abort the rest of the machine bootstrap.
6. Windows verification still treats missing Notion as a desired-state failure. Bootstrap continuity and final desired-state verification are separate guarantees.

## Consequences

- A transient or vendor-specific Notion installer failure no longer prevents Git, mise, developer tools, or other applications from converging.
- Notion is no longer represented in `mise bootstrap packages status`; `platforms/windows-11/verify.ps1` owns its presence check.
- The Windows bootstrap gains one vendor-specific installation adapter.
- Existing NSIS installations remain valid until explicitly migrated; this decision does not force replacement on already-configured machines.

## Re-evaluation triggers

Reconsider this decision if:

- the Notion WinGet package moves to a reliable MSIX/App Installer channel,
- mise gains per-package optional/failure-policy semantics suitable for this boundary,
- Notion removes or materially changes the official MSIX distribution,
- the repository adopts a general Windows optional-GUI application phase.
