# ADR-0015: Windows / macOS のクリップボード同期に UniClipboard を採用する

- Status: Accepted
- Date: 2026-10-17
- Related: ADR-0006, ADR-0009

## Context

Windows 11 (Ethernet) と macOS (Wi-Fi) を同一の `192.168.2.0/24` アドレス帯で使用しても、両者の間で ARP 解決ができないネットワーク環境がある。CrossPaste の LAN 依存の検出・通信では同期が成立せず、有線 LAN を外すと動作した。これを回避するためのユーザーによるネットワーク切替・経路調整は desired state としない。

UniClipboard はこの実機構成で同期動作を確認済みであり、直接接続できない場合の中継経路に対応する。クリップボードのテキスト・URLに加え、軽いファイル共有も対象とする。

## Decision

- Windows / macOS の常用クリップボード同期アプリを UniClipboard とする。CrossPaste は desired state に含めない。
- macOS は `mise.global.toml` の `[bootstrap.packages]` に `brew-cask:UniClipboard/tap/uniclipboard` を `os = "macos"` 付きで宣言する。公式 Homebrew tap を使用する。
- Windows は `platforms/windows-11/apps.psd1` に `UniClipboard.UniClipboard` を追加する。既存の Windows デスクトップアプリと同様、個別 best-effort install + strict verify の対象にする。開発ツールの mandatory WinGet phase に入れない。
- 実機に一時的に追加した `mise bootstrap packages use -g winget:UniClipboard.UniClipboard` の重複宣言は整理し、Windows の GUI inventory を canonical にする。
- ペアリング（Space 招待・認証）や暗号鍵はユーザーごとの手動設定であり、repository、snapshot、Infisical へコピーしない。CLI install だけでペアリング済みとはみなさない。
- 既に導入した CrossPaste は両端末でユーザーが明示的にアンインストールする。環境 bootstrap がほかのソフトを自動的に消すことはしない。

## Consequences

- 端末間の L2 通信や有線・無線の同一セグメントを要件にしない。ただし中継経路はインターネット到達性に依存する。
- Windows/macOS の package desired state は repository に同期されるが、実際のアプリデータとペアリング状態は同期しない。
- Windows の app installer が失敗しても、その 1 件だけを記録して後続 bootstrap を続行できる。

## Re-evaluate

- UniClipboard の中継が日常環境で不安定になった場合
- 暗号化・信頼モデルに対して要件を満たせない変更が加わった場合
- CLI 経由で安全かつ非対話的に Space を復元できるようになった場合
